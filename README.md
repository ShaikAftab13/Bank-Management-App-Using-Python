This Bank Management App is a Python + Streamlit based digital banking system that simulates real-world payment apps. 
Users can create accounts, deposit and withdraw money, view balances, update details, and manage data securely using JSON with a clean, app-like UI.

How to Run the App:


Step 1 :pip install streamlit
Step 2 : python -m streamlit run app.py


Once started, the app will automatically open in your browser and display the interactive banking dashboard.
